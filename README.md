# 📊 Markdown 字数统计工具

一个简洁的命令行工具，用于统计 Markdown 文件的字数，支持中文字符和英文单词分别统计。

## ✨ 功能特点

- 📄 读取 Markdown 文件并统计字数
- 🇨🇳 中文字符单独统计
- 🇬🇧 英文单词单独统计
- 📏 总字符数统计
- 📦 零依赖，原生 Node.js 实现

## 🚀 安装使用

### 直接运行

```bash
node index.js <文件路径>
```

### 全局安装

```bash
npm link
md-word-count <文件路径>
```

## 📖 使用示例

```bash
# 统计测试文件
npm test

# 或者直接运行
node index.js ./test.md
```

**输出示例：**

```
📄 文件：test.md
📏 文件大小：0.63 KB

📊 统计结果：
  ├─ 总字符数：    156 个
  ├─ 中文字数：    89 个
  └─ 英文单词数：  32 个
```

## 🛠️ 技术实现

### 统计逻辑

| 统计项 | 正则表达式 | 说明 |
|--------|-----------|------|
| 总字符数 | `text.replace(/\s/g, '').length` | 去除所有空白后的长度 |
| 中文字符 | `[\u4e00-\u9fa5]` | Unicode 中文字符范围 |
| 英文单词 | `[a-zA-Z]+` | 连续英文字母 |
